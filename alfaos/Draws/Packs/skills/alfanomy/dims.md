# Dimensions

- The dimension stage is none or given. In stage given only the fields marked in given are dimensioned, so mark exactly what was read from the input and nothing else.
- Turn dimensions on with set_style dimensions true only when the person wants a workshop drawing; a presentation view stays calm without them.
- Dimension chains are computed by the engine from the part edges. Align edges (shared x, z levels) so chains stay short; do not add parts only to carry a dimension.
- Millimetres everywhere. Never write units into names.
