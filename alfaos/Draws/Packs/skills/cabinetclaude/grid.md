- Heights add up: plinth 80 + carcass 800 + worktop 40 = 920 worktop height; tall units 80 + height.
- Corner wall 675 closes an L run above corner L 880; blind corner 1280 needs one door-width neighbour.
- Fill the run length with standard widths, put the odd rest in one filler at a wall end.
- Tall, fridge and top stack: a top cabinet (kind top) sits on the cabinet before it.
- Half-high and filler have no own kind: use tall with a free height, or a narrow base; name them in the assumptions.
