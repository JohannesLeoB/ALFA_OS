„Achtung! „Mykilos“ und alle Abwandlungen davon sollen nicht in App Code oder tokens oder Meta etc auftauchen! alfa kein mykilos!!!“ · „Das ist wichtig!!!“ · „Also bestenfalls auch „myk“ etc. auf Streichliste zum kontinuierlichen entfernen /ersetzen und neu mit verknüpften files und Funktionen, Ui usw wiren“ (19.10.2026, Lead-Sitzung)
**Why:** Die App ist ALFA, für Distribution gedacht (siehe [[reichweite-der-app]]); ein Firmenname im Code bindet sie an ein Studio.
**How to apply:** Streichliste (Suche ohne Groß-/Kleinschreibung): `myk` als Wortteil, also mykilos, mykilOS, Mykilos*, Myk*, myk-*. Bei jeder Arbeit fortlaufend entfernen oder ersetzen und die verknüpften Dateien, Funktionen und die UI mit neu verdrahten, so dass der Build strikt bleibt. Kein „mykilos“ (jede Schreibweise) in Swift, Modul- und Paketnamen, Tokens, $extensions (Schlüssel heißt `alfa`), JSON-Feldern, Schemas, IDs, Kommentaren. Bestand: 40 Swift-Dateien in alfaos/ importieren `MykilosKit` und `MykilosServices` (Paket „alpha“), `alfaos/Kit/Package.swift` nennt sie 7-mal; Ablösung ist ein Bauauftrag auf Johannes' Wort. Pfade im Bestand (Labor, Fundus) dürfen in Strang-Definitionen als Leseort stehen, nie im Code.
